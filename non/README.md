# non

這個目錄保存正式網站不會載入的內容，避免歷史版本與產製檔混入根目錄。

- `legacy-v1/`：舊版網站、後台與爬蟲。
- `generated/`：已被正式程式取代的生成檔、清理前版本、舊分離資料與確認沒有呼叫點的程式碼。
- `raw-data/`：大型來源資料；預設不提交 Git。
- `research/`：一次性分析腳本與早期規格。
- `trace-source/`：二值化圖片、輪廓 JSON 與檢查圖；正式頁面的執行資料已整合到 `assets/js/venue-maps.js`。

若要恢復歷史程式，請先複製回正式目錄並重新檢查引用，不要直接從 `non/` 載入。
